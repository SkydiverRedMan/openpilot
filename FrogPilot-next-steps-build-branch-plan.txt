Native UI guidance
------------------
Do not retry the previous one-file native UI transplant.

Historical result:

- Building `selfdrive/ui/ui` directly on the comma produced an ARM64 binary.
- The binary contained the Navigation Assist button text.
- Installing that one rebuilt binary caused boot-logo/UI instability.
- Wayland environment tweaks and manager launch workarounds were not enough.
- Rolling back to the old prebuilt UI restored stability.

Future native UI work should use a complete, matching prebuilt release process from one source commit. If the goal is a personal/test action, prefer The Pond web UI instead of the native Qt UI.

Rules going forward
-------------------
1. Keep comma install branches lean.
2. Keep notes and showcase assets off install branches.
3. Do not add new persistent params to a prebuilt branch unless the matching compiled params extension is rebuilt.
4. Direct asset changes such as sounds and boot images are usually safe on prebuilt install branches.
5. C++ UI, schemas, DBC generator work, and compiled extensions need source-branch discipline and a real build/release path.
